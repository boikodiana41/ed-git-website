# Bloom Studio
Bloom Studio es una floristería ficticia especializada en la creación de ramos personalizados, decoración floral y arreglos para eventos especiales.

## Tecnologías utilizadas
- HTML
- CSS

## Cómo abrir la página web
1. Descargar o clonar este repositorio.
2. Abrir el archivo `index.html`.
3. La página web se mostrará en el navegador.
